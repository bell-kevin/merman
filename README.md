# merman

`merman` auto-generates a Mermaid architecture diagram for any **public GitHub repository**.

It can:
- scan a local repository checkout, or
- clone a public GitHub URL,
- infer high-level components from folders/files,
- optionally infer Python import relationships,
- write the Mermaid diagram to a file (for example `docs/architecture.mmd`).

---

## Quick start (template repository friendly)

1. Copy these files into your repository template:
   - `scripts/generate_merman_diagram.py`
   - `.github/workflows/update-merman-diagram.yml`
2. Commit them to your template.
3. Every new repository created from the template will now auto-regenerate `docs/architecture.mmd` on pushes to `main`/`master`.

---

## Local usage

Generate from the current repository:

```bash
python3 scripts/generate_merman_diagram.py \
  --repo-path . \
  --output docs/architecture.mmd
```

Generate from a public GitHub URL:

```bash
python3 scripts/generate_merman_diagram.py \
  --repo-url https://github.com/OWNER/REPO \
  --output docs/architecture.mmd
```

---

## Automatic updates with GitHub Actions

The included workflow (`.github/workflows/update-merman-diagram.yml`) will:

- run on every push to `main`/`master` (except when only `docs/architecture.mmd` changed),
- regenerate `docs/architecture.mmd`,
- commit and push the updated diagram if its content changed.

You can also run it manually via **Actions → Update Mermaid Architecture Diagram → Run workflow** and optionally provide:

- `repo_url` (public GitHub URL)
- `output_path` (defaults to `docs/architecture.mmd`)

---

## Notes

- The generator intentionally skips common heavy/build directories (for example `.git`, `node_modules`, `.venv`, `dist`, `build`).
- The diagram is deterministic (stable ordering) to avoid noisy commits.
- The generated Mermaid file starts with:

```text
%% Generated by merman. DO NOT EDIT BY HAND.
```

If you want richer architecture inference later (language-specific dependency extraction, service boundaries, etc.), you can extend `scripts/generate_merman_diagram.py` while keeping the same workflow.
